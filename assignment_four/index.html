Intent Prioritization Pipeline

The FAQ Bot processes user statements through a sequential normalization and priority classifier:

Stage Processor Operation
1. Text Normalization normalize_text() Lowercases, removes punctuation, collapses whitespace into single space.
2. Command Interceptor is_exit_command() / is_help_command() Immediately catches session commands (quit, exit, bye, help).
3. Conversational Flow is_greeting() Greets the student without consuming FAQ search logic.
4. Specific Regex Matching intent_patterns Prioritizes specific nouns (certificate, submission, GitHub) ahead of general timing keywords.
5. Grounded Fallback FALLBACK_MESSAGE If no verified answer exists in the JSON dataset, informs the user rather than hallucinating facts.
