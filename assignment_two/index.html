Stock Portfolio Performance Tracker

A financial valuation utility engineered in Python 3.10+. Calculates invested capital, current valuation, and gain/loss return percentages while validating ticker symbols against S&P 500 constituents and exporting audit CSVs.

Terminal Execution Guide View Project README ← Back to Studio Home
EDUCATIONAL USE DISCLAIMER:

This application is constructed strictly for educational demonstration of financial formulas, data validation, and CSV export routines. It does not provide real-time trading facilities or investment advice.

Valuation Formulas & Metrics

All performance calculations use standard financial formulas with 2-decimal rounding precision:

Metric Formula Definition Behavior with Missing Price
Invested Capital Purchase Price × Quantity Always computable from entry transaction.
Market Value Current Price × Quantity Marked UNPRICED; excluded from total valuation.
Gain / Loss ($) (Current Price − Purchase Price) × Quantity Marked N/A; zero fabrication policy enforced.
Gain / Loss (%) ((Current Price − Purchase Price) / Purchase Price) × 100 Marked N/A.
