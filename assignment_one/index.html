Console Hangman Word Game

An interactive, modular console word puzzle developed in Python 3.10+. Features a 7-stage ASCII gallows, strict single-character validation, duplicate guess immunity, and dictionary fallback mechanisms.

Terminal Execution Guide View Project README ← Back to Studio Home

Core Requirements & Architecture

The application is structured into decoupled components separating input validation, game state management, and terminal presentation:

Component Class / Function Responsibility
Vocabulary Loader DictionaryLoader Loads 9,800+ English words from local data cache; applies word length bounds (4-10 chars); activates safe offline fallback list if missing.
State Manager HangmanGame Tracks secret word, guessed letters set, lives remaining (max 6), victory/loss state, and masked word formatting (p _ t h _ n).
ASCII Renderer STAGES tuple 7-stage progressive gallows graphics reflecting exact error counts (0 to 6 errors).
Terminal Loop run_console_session() Prompts player for letter guesses, validates inputs, catches Ctrl+C and EOFError, and handles replay loops.

Dataset Provenance

Vocabulary is sourced from the official Google 10,000 English word repository:

  • Dataset Source: first20hours/google-10000-english-no-swears.txt
  • Local File Path: assignment_one/data/words.txt
  • Total Verified Words: 9,894 entries
  • Fallback Policy: Built-in immutable tuple of programming terminology ensures the game functions even if the file is moved or deleted.
