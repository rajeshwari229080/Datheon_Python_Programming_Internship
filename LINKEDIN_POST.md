• High-speed categorizer routing messy directories into 9 functional clusters (Images, Documents, Source Code, etc.).
• Non-destructive auto-incrementing collision protection (`file_1.ext`) preventing accidental file overrides.

• Priority regex intent mapping and strict token normalization for natural query variations.
