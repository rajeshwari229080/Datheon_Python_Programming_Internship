Automated File Organizer

A resilient CLI filesystem utility built in Python 3.10+ using pathlib and shutil. Automatically segregates disorganized files into 9 structured functional categories with dry-run previews, non-destructive collision renaming, root guard safety, and operation logging.

The 9 Functional Categories

Files are classified based on lowercase extension mapping:

Category Common Extensions Handled Destination Directory
Documents .pdf, .docx, .doc, .txt, .rtf, .odt, .md <target>/Documents/
Images .jpg, .jpeg, .png, .gif, .bmp, .svg, .webp <target>/Images/
Videos .mp4, .mkv, .avi, .mov, .wmv, .webm <target>/Videos/
Audio .mp3, .wav, .aac, .flac, .ogg, .m4a <target>/Audio/
Archives .zip, .tar, .gz, .7z, .rar, .bz2 <target>/Archives/
Source Code .py, .js, .ts, .html, .css, .java, .cpp, .sql <target>/Source Code/
Spreadsheets .xlsx, .xls, .csv, .tsv, .ods <target>/Spreadsheets/
Presentations .pptx, .ppt, .key, .odp <target>/Presentations/
Other All unrecognized or unclassified file types <target>/Other/

Safety Safeguards & Collision Policy

  • Drive Root Protection: Refuses to process filesystem roots (e.g. C:\, /) or Windows operating system folders to prevent inadvertent damage.
  • Non-Destructive Collisions: If report.pdf already exists in Documents/, an incoming file of the same name is automatically moved as report_1.pdf without data loss.
  • Dry-Run Mode: Using --dry-run previews all classifications without writing to disk or creating folders.
  • Folder Skipping: Avoids re-processing existing category subdirectories, hidden dotfiles (e.g. .gitkeep), and symlinks.

Terminal Execution Instructions

1. Dry-Run Simulation (Preview Only)

python assignment_three/file_sorter.py --target "path/to/folder" --dry-run

2. Interactive Organization with Confirmation

python assignment_three/file_sorter.py --target "path/to/folder" --interactive
