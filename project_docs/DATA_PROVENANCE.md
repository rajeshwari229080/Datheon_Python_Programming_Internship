## 1. Overview of External Datasets

CodeCraft Python Studio utilizes three primary external reference datasets. In accordance with strict academic and provenance standards, all datasets were fetched directly from canonical public endpoints, verified locally, and isolated within their respective assignment directories.

## 2. Dataset Verification Records

### 2.1 Assignment One — Hangman English Vocabulary
- **Dataset Title:** Google 10,000 Most Common English Words (No Swears)
- **Canonical URL:** [https://raw.githubusercontent.com/first20hours/google-10000-english/master/google-10000-english-no-swears.txt](https://raw.githubusercontent.com/first20hours/google-10000-english/master/google-10000-english-no-swears.txt)
- **Local Destination:** `assignment_one/data/words.txt`
- **Format:** Plain text newline-delimited ASCII strings
- **Line Count:** 9,894 valid vocabulary entries
- **Character Filtering:** Filtered for alphabetic characters between 4 and 10 characters in length.
- **Fallback Mechanism:** If the file is inaccessible or deleted, `DictionaryLoader` falls back to an internal hardcoded tuple of software engineering terms (`python`, `studio`, `variable`, `developer`, etc.), maintaining zero-crash resilience.

### 2.2 Assignment Two — S&P 500 Corporate Constituents
- **Dataset Title:** S&P 500 Companies Constituent Index
- **Canonical URL:** [https://raw.githubusercontent.com/datasets/s-and-p-500-companies/master/data/constituents.csv](https://raw.githubusercontent.com/datasets/s-and-p-500-companies/master/data/constituents.csv)
- **Local Destination:** `assignment_two/data/constituents.csv`
- **Format:** Comma-Separated Values (CSV) with UTF-8 encoding
- **Header Columns:** `Symbol`, `Security`, `GICS Sector`, `GICS Sub-Industry`, `Headquarters Location`, `Date added`, `CIK`, `Founded`
- **Record Count:** 503 company entries
- **Pricing Status Note:** This dataset contains static corporate metadata only. In adherence to the project specification, it is **never** used as a source for real-time stock prices. Market prices must be entered manually or derived from documented market sources.
- **Fallback Mechanism:** If the file is missing, the application continues to process user portfolio calculations and issue CSV reports without symbol lookup validation.

### 2.3 Assignment Three — Standard Filesystem Reference
- **Technical Reference:** Python Standard Library `shutil` and `pathlib` documentation
- **Reference URL:** [https://docs.python.org/3/library/shutil.html](https://docs.python.org/3/library/shutil.html)
- **Testing Safeguard:** All automated tests execute strictly against isolated temporary directories generated by `tempfile.TemporaryDirectory()`. The organizer never operates on personal or system root directories.

### 2.4 Assignment Four — Datheon Internship FAQ Knowledge Base
- **Dataset Title:** Datheon Sample FAQ Dataset
- **Canonical URL:** [https://www.datheon.in/datasets/sample_faq.json](https://www.datheon.in/datasets/sample_faq.json)
- **Local Destination:** `assignment_four/data/sample_faq.json`
- **Format:** JSON structure containing `greetings` array and `faqs` list of question/answer objects
- **Verified Schema:**
  ```json
  {
    "greetings": ["hello", "hi", "hey", ...],
    "faqs": [
      {
        "question": "What are your hours of operation?",
        "answer": "We operate Monday through Friday from 9:00 AM to 6:00 PM IST."
      },
      ...
    ]
  }
  ```
- **Strict Grounding Rule:** The bot answers only questions present in the dataset. Missing or ambiguous questions receive a clear fallback notification directing the student to official program coordinators.
